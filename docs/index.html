How It Works

四個步驟，自動化處理用量上限

用量未滿時完全零干擾；只有在達到上限時才溫柔接手，絕不弄丟你辛苦寫好的 prompt。

01

照常輸入並送出

不需要改變任何使用習慣。用量未滿時擴充功能完全不攔截；按 Enter 或送出按鈕才會觸發檢查（完整相容中文輸入法組字）。

02

安全存入本機佇列

確認用量已滿後，將文字、本機附件與原對話網址存入 Chrome 本機儲存空間，確認存檔成功後才清空輸入框。

03

重置確認與桌面通知

到了預計重置時間（＋30 秒緩衝）自動確認額度是否真的恢復；若尚未重置會每 2 分鐘重試，恢復後立刻發送桌面通知。

04

一鍵填回或自動送出

點擊通知開啟原對話、自動填回文字與上傳附件，按下確認列的「送出」即可。也可依需求在設定頁開啟「自動送出」。

Features

為重度 claude.ai 使用者打造的完整細節

從 ProseMirror 富文字編輯器還原到多分頁防重複鎖定，每個邊緣情況都仔細處理。

📎

文字與本機附件一起排隊

從電腦選檔、拖放或貼上的圖片與 PDF 會存進擴充功能專屬 IndexedDB，重置後自動加回輸入區並等上傳完成才送出，送出後即刪除暫存。

⏱️

精準的重置時間偵測

優先讀取 claude.ai 用量端點取得精確百分比與重置時間；若端點失敗自動切換至頁面提示文字解析，並清楚標示是否為「估計」時間。

🌙

睡前自動重設（選用）

5 小時工作階段歸零時，自動在專用對話用 Haiku／中 送出一則短訊讓下個工作階段立即開始倒數，早上起床即可連續使用兩個工作階段。

🛡️

嚴謹的防重複送出機制

Service Worker 以 promise mutex 序列化佇列操作，搭配分頁 Claim 鎖定與對話訊息比對，即使開多個分頁或手動已送出也不會重複發送。

✍️

原生級輸入框還原

專為 claude.ai 的 ProseMirror 編輯器設計，支援多行、空行與長文還原；即使未來介面改版導致填入失敗，訊息仍安全保留並提供一鍵複製。

🔔

可控的送出模式與更新通知

預設為「桌面通知＋手動確認列」，自動送出需手動開啟且附帶 3 秒取消倒數。從 GitHub 安裝時每日自動檢查一次新版本（可關閉）。

Installation

5 分鐘完成安裝，零建置步驟

純 JavaScript 撰寫、不需要 Node.js 或任何打包工具，載入 Chrome 即可直接使用。

  1. 1
    下載並解壓縮原始碼

    前往 GitHub 專案頁面，按綠色的 Code → Download ZIP，解壓縮得到 claude-queue-main 資料夾，並移到固定位置（例如「文件」資料夾，安裝後請勿刪除或移動）。

  2. 2
    開啟 Chrome 擴充功能管理頁

    在 Chrome（版本 116 以上）網址列輸入以下網址並按 Enter，開啟右上角「開發人員模式」開關：

    chrome://extensions
  3. 3
    載入未封裝項目

    點擊左上角「載入未封裝項目」，選擇剛剛解壓縮的資料夾（注意：要選裡面直接包含 manifest.json 的那一層）。

  4. 4
    釘選圖示並重新整理 claude.ai

    點 Chrome 右上角拼圖圖示 🧩 將 Claude Queue 釘選 📌 到工具列，然後重新整理已經開啟的 claude.ai 分頁（⌘R / Ctrl+R），點工具列圖示看到用量百分比即安裝成功！

  1. 1
    Clone 儲存庫至本機

    在終端機執行以下指令，之後要更新只要 git pull 並在擴充功能頁點重新整理即可：

    git clone https://github.com/ivantw829/claude-queue.git
  2. 2
    載入至 Chrome

    前往 chrome://extensions → 開啟「開發人員模式」→ 按「載入未封裝項目」→ 選取 claude-queue 資料夾。

  3. 3
    釘選圖示並重新整理分頁

    釘選 Claude Queue 至工具列，重新整理已開啟的 claude.ai 分頁。想搶先體驗流程，可在設定頁開啟「模擬用量已滿」進行測試。

🔔 提醒：開啟系統桌面通知
macOS 請至「系統設定 → 通知 → Google Chrome」開啟允許通知（建議將樣式設為「提示」）；Windows 請至「設定 → 系統 → 通知」確認 Google Chrome 已開啟。完整圖文步驟與試玩教學請參考 GUIDE.md 新手教學。
Workflow & Advanced

工具列狀態與進階自動化

一目了然的佇列狀態燈號，以及專為高頻使用者設計的睡前自動重設與自動送出。

🎛️ Popup 小視窗與狀態燈號

點擊工具列圖示即可隨時查看 5 小時 Session 與每週用量百分比、倒數時間與佇列清單。每則排隊訊息都支援直接編輯文字、立即嘗試送出或兩段式確認刪除。

工具列圖示會以數字與顏色即時反映佇列狀態：

橘色：等待重置中 綠色：額度已恢復可送出 紅色：有失敗項目需確認

💡 同一對話排入多則訊息時，會依照順序等待 Claude 回應完成後再依序還原下一則。

🌙 睡前自動重設（選用，預設關閉）

claude.ai 的 5 小時工作階段需等你送出第一則訊息才開始倒數。開啟「自動重設」後，工作階段歸零（＋90 秒緩衝）時會在專用對話自動送出一則短訊（預設 Hello World!，並切換為最省額度的 Haiku／中），讓新週期馬上開始倒數。

  • Chrome 需保持開啟且 claude.ai 維持登入
  • 電腦不可進入睡眠（macOS 可在終端機執行 caffeinate -i）
  • 若你已用手機發過訊息，或佇列正自動送出，則不會重複觸發
  • 連續失敗 3 次自動暫停並通知，保護帳號安全
caffeinate -i
Privacy & Architecture

100% 本機運作，隱私透明可檢驗

純 JavaScript 原始碼完全公開，沒有後端伺服器、不追蹤、不上傳任何你的對話內容。

🔒

全部資料留在本機瀏覽器

佇列文字、用量快照與設定存於 chrome.storage.local，附件存於擴充功能專屬 IndexedDB。送出或刪除時同步清除。

🧩

最小必要權限原則

僅要求 storage、alarms、notifications 三項權限，且只在 https://claude.ai/* 運作，不觸碰任何其他網站。

🧭

不偽造請求、不繞過限制

送出一律透過頁面上的輸入框與送出按鈕操作，跟你親手點擊完全一樣；不會呼叫或重放 claude.ai 聊天 API。

📝

去識別化 Debug Log

除錯日誌只記錄事件類型、ID、字數與附件大小，絕不記錄訊息內容與檔名。網路請求僅同源 GET 用量與選用的 GitHub 版本號檢查。

想了解完整細節？請參閱 PRIVACY.md 隱私權政策 與 TESTING.md 測試清單。

Transparency

已知限制與維護說明

開源工具講求誠實透明——以下情境請先了解，遇到 claude.ai 改版時也能快速定位修正。

項目 目前支援狀態與處理方式
支援平台 僅支援 claude.ai 網頁版（含 Projects），不支援 Claude 桌面 App、手機 App 與 Claude Code。
附件類型 支援從電腦選檔、拖放與貼上的圖片／檔案（單檔 ≤ 30MB、最多 20 個、總佇列 ≤ 300MB）。Google Drive／GitHub 連接附件與長文字轉成的附件無法保存，會照原本方式處理並提示。
純附件訊息 只有附件、沒有任何文字的訊息不會排隊（因重複送出偵測依賴文字比對）。
自動送出前提 需 Chrome 維持開啟、電腦未睡眠且保持登入；若不符合會在下次開啟或喚醒時補檢查。自動送出秉持「寧可不送，也不送錯對話」原則。
claude.ai 介面改版 所有 DOM 選擇器集中在 src/content/selectors.js，用量解析集中在 src/content/usage.js，改版時易於維護。若失效請開 Debug Log 並至 GitHub Issues 或 Discord 回報。
FAQ

常見問題

關於安全性、附件、睡眠狀態與相容性的快速解答。

這會讓我多用額度或繞過限制嗎？

不會。它只是在你被擋的時候把訊息存起來，等額度恢復後再透過頁面上的送出按鈕送出，跟你自己晚點回來貼上送出完全一樣。它不會呼叫 claude.ai 的聊天 API，也不會重放任何請求。

我的訊息與附件會被傳到哪裡？

哪裡都不會。佇列文字只存在你 Chrome 的 chrome.storage.local，附件存在擴充功能專屬的 IndexedDB，重置後直接透過 claude.ai 頁面本身送出。開發者完全不會收到任何你的資料。

可以傳檔案或圖片嗎？

可以。用量沒滿時完全正常；用量已滿時，你從電腦加入的檔案（選檔、拖放、貼上圖片）會連同文字一起排隊，重置後自動加回輸入區並等上傳完成再送出。Google Drive 等連接的附件則無法保存，會照原本方式處理並提示你。

電腦睡眠或 Chrome 關閉時會怎樣？

Chrome 關閉時無法發通知。下次開啟 Chrome 時，擴充功能會依佇列自動重建排程；如果重置時間已經過了，會立刻檢查並通知你。電腦睡眠中錯過的排程，醒來後也會自動補觸發。

開啟「自動送出」安全嗎？

自動送出預設為關閉，開啟前會跳出確認對話框。啟用後會在重置時自動開啟分頁並填入文字，送出前仍有 3 秒倒數可取消；若原對話已刪除或輸入框已有草稿，會自動保護草稿或停止送出並發通知。

支援 Edge、Brave、Arc 嗎？

這些 Chromium 系瀏覽器理論上都能用「載入未封裝項目」安裝使用，不過目前主要在 Google Chrome 116+ 上開發測試。歡迎在 Discord 分享你的使用結果！
